# 设计说明提纲

用户需要设计报告时按实际结果填写，不把计划写成已验证能力。

| 部分 | 必须说明 |
| --- | --- |
| 框架与环境 | 实际开源库和版本、工具、运行环境；没有第三方 Agent 框架就如实说明 |
| 整体工作流 | 模板读取→规则提取→内容映射→写入→检查→修复 |
| 模板理解 | 文字、示例、样式、页面结构及冲突、缺失信息处理 |
| Agent 与工具分工 | 语义判断与确定性代码各自职责及理由 |
| 文档生成策略 | 保留、重建或混合的依据，封面与布局保护 |
| 检查与失败修复 | 结构、内容、渲染检查；至少一个真实失败的发现、原因、修复和验证 |
| 编辑与更新能力 | 目录、文献、公式与交叉引用的实现和已验证范围 |
| 通用性与边界 | 新模板复用能力、人工判断、未见模板验证及限制 |
| 当前结果与未解决问题 | 每份成稿实际状态、验证结果、剩余问题和真实尝试 |
| 复跑与证据索引 | 统一入口、各次命令、实现版本、日志与真实工具轨迹 |
